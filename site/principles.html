  • Principles
  • Issues as queue, labels as state. One source of truth that both the factory and a human can edit with the same tool.
  • Scripts where the step is deterministic, agents where it is not. Moving a note into an issue, or picking the oldest planned issue, needs no model. Writing acceptance criteria, writing code, and judging a diff do.
  • Three agents, not one. The agent that writes code must not be the one that decides the code is good. Separate prompts, separate sessions, separate context.
  • Bounded seats, bounded time. Capacity per phase and a timeout per phase are what make the factory's cost and latency predictable, and what make a stuck agent a visible event instead of a silent one.
  • Hard guards, not agreements. Every Build runs in its own worktree: its own branch and directory, created on spawn and cleaned up on archive. Parallel tasks cannot collide, and nothing an agent does there reaches main, because merging is the factory's and not the agent's. The working agreement tells agents the rules; the worktree is what enforces them.
  • Full permissions inside the blast radius. An unattended loop that waits on a permission prompt is a stalled loop. The worktree and the branch are the blast radius.
  • Every agent leaves an artifact. A plan, a gated pull request, a review, each with a fixed shape the factory can refuse. A summary in chat is not an output.
  • The gate is a tool, not a judgement. The agent runs it, the tool writes the report. A passing report means the checks passed, not that the agent said so.
  • Retries re-run everything, and carry the past. A failed task goes through every phase again, prompted with the reasons and with links to the failed threads. Those threads stay open for a human to comment in, and the branch stays for Build to continue from.

Why three

One agent doing all three phases has read its own plan, trusts its own checks and reviews its own diff. Each hand-off forces the output into an artifact a stranger can act on and the factory can refuse. The artifacts are the product, and they ship with the code. Each agent can be replaced by a better prompt, and each phase given more seats or a different timeout, without touching the others.
