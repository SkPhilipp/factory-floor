Five phases. Backlog is a queue, Release is an automation, the three in between are staffed by agents. Build ends with a quality gate: a tool the agent must run before it may hand off. Release is the system merging what Review passed; no human approves a merge.

The numbers are the starting configuration, not a law; each is a setting per repository.

Every artifact is a file in the repository under factory/, committed on the task's branch. In the paths N is the issue number and A the attempt, so the second attempt at #42 writes factory/plans/42-2.md and 42-1.md stays next to it. Files under factory/ do not count for a plan's constraints, or the gate would fail on its own report. One task, one worktree, one thread per phase: the Intake thread gets a fresh worktree on branch factory/42, and the Build and Review threads, and every retry's threads, are spawned into that same worktree.
