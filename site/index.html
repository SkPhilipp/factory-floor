The Dark Factory

A dark factory runs with the lights off. Work goes in, reviewed pull requests come out, and nobody watches the loop. A human reads results, not progress.

This site was written by the factory it describes. Every page arrived as a GitHub issue, was planned by an Intake agent, built by a Build agent behind a quality gate, judged by a Review agent and merged by the Release automation. There was no human in the loop: no human wrote, reviewed or merged a page.
