# Plan for #1, attempt 1

## Goal

Scaffold the Dark Factory static site: a home page, a dark stylesheet, a Node check command and a README, so later issues can each add one page. Plain HTML and CSS, no framework, no build step. The issue fits in one pull request; no split.

## Scope

- `site/index.html`: `<title>The Dark Factory</title>`, a link to `style.css`, one visible `<h1>The Dark Factory</h1>` (the issue says the page shows the title; the h1 is expected, not extra), then one `<p>` with exactly: "A dark factory runs with the lights off. Work goes in, reviewed pull requests come out, and nobody watches the loop. A human reads results, not progress." Below it a `<nav>` containing a `<ul>` with a single `<li><a href="index.html">Home</a></li>`.
- `site/style.css`: background `#151517`, text `#f2f3f5`, muted text `#b8bcc4`, link accent `#7fb58a`, system sans-serif body font stack, serif font for headings, content column `max-width: 760px`, tables with `1px solid #2e2e31` borders.
- `package.json`: `"scripts": { "test": "node check.mjs" }`, no dependencies.
- `check.mjs`: walks `site/` recursively; for each `.html` file reports one line per problem (missing `<title>`, missing `<link rel="stylesheet" href="style.css">`, relative `href` to a file not present in `site/`; ignore `http:`, `https:`, `mailto:` and `#` anchors, strip fragments and queries). Exits non-zero if any problem, otherwise prints `ok: N pages`. Uses only Node built-ins.
- `README.md`: two sentences on what the site is, naming `npm test` as the check.

## Constraints

- May touch only `site/index.html`, `site/style.css`, `package.json`, `check.mjs`, `README.md`. Files under `factory/` do not count.
- Must not add dependencies, a lockfile, a build step, JavaScript in the site, or other pages.
- Must not alter the paragraph text or colours given in the issue.
- Budget: at most 5 files changed, under 150 added lines in total.

## Acceptance criteria

- [ ] `site/index.html` has the title `The Dark Factory`, an `<h1>` with the same text, and exactly one `<p>` with the issue's paragraph verbatim.
- [ ] `site/index.html` contains a `<nav>` with a `<ul>` whose only item is a link `href="index.html"` labelled `Home`.
- [ ] `site/index.html` contains `<link rel="stylesheet" href="style.css">`.
- [ ] `site/style.css` contains `#151517`, `#f2f3f5`, `#b8bcc4`, `#7fb58a`, `#2e2e31`, `760px`, and a `serif` heading font rule.
- [ ] `package.json` is valid JSON, has `scripts.test` equal to `node check.mjs`, and has no `dependencies` key.
- [ ] `check.mjs` exits non-zero and prints one line per problem when a page lacks a title, lacks the stylesheet link, or has a relative `href` to a missing file; it prints `ok: N pages` otherwise.
- [ ] `README.md` has two sentences and mentions `npm test`.
- [ ] Only the five files listed in Constraints (plus `factory/`) differ from the base branch.

## Proofs

- `npm test` — exits 0 and prints `ok: 1 pages`.
- `test -f site/index.html && test -f site/style.css && test -f check.mjs && test -f package.json` — exits 0.
- `node -e "const p=require('./package.json');if(p.scripts.test!=='node check.mjs'||p.dependencies)process.exit(1)"` — exits 0.
- `grep -c "A dark factory runs with the lights off. Work goes in, reviewed pull requests come out, and nobody watches the loop. A human reads results, not progress." site/index.html` — prints `1`.
- `grep -q '<link rel="stylesheet" href="style.css">' site/index.html` — exits 0.
- `grep -q 'href="index.html"' site/index.html` — exits 0.
- `grep -q -e '#151517' -e '#f2f3f5' -e '#b8bcc4' -e '#7fb58a' -e '#2e2e31' site/style.css` — exits 0.
- `grep -q 'max-width: 760px' site/style.css` — exits 0.
- `d=$(mktemp -d) && cp -r site "$d/site" && echo '<p><a href="nope.html">x</a></p>' > "$d/site/bad.html" && cp check.mjs "$d/" && (cd "$d" && ! node check.mjs)` — exits 0, proving the check fails on a page with no title, no stylesheet and a broken link.
