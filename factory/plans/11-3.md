# Plan for #11, attempt 3

## Goal

Ship `site/floor.html`, "The floor", linked from the nav on `site/index.html` as "Floor", as built in attempts 1 and 2 (`factory/plans/11-1.md`, `factory/plans/11-2.md`): the issue's intro, the Fact / Source / Readable as table with nine rows, a static CSS 3D scene of five phase columns with pads, lights, cards, strike dots and timeout bars, a throughput tally and the closing paragraph on the ideas that did not ship first. No JavaScript, no canvas, no WebGL. Live state, orbit and click-through stay in #17 (open, label `factory`).

The page already exists on this branch and passed the gate twice. Attempt 1 failed because the branch did not merge into master. Attempt 2 merged master, but master has since gained `site/backlog.html`, `site/build.html`, `site/intake.html` and three more nav items, so `site/index.html` conflicts again; its Review then timed out. This attempt (1) merges master again, (2) fixes one layout defect Review found, and (3) keeps the work small so Review finishes: no rewrite of the page.

## Scope

- First step: `git fetch origin && git merge origin/master` on this branch (a merge commit; no rebase, no force-push). The expected conflict is in `site/index.html`: keep every nav item master has, in master's order, and append `<li><a href="floor.html">Floor</a></li>` last. If `site/style.css` conflicts, keep both sides, master's rules first and the floor rules after. Do this before anything else, and push early.
- Fix in `site/style.css`: a `.seat .card` is absolutely positioned inside a `.seat` of `height: 64px`, but a card with title, five dots and a bar is taller and overflows into the next seat. Make `.seat` tall enough to hold a held card (at least `96px`, via `height` or `min-height`) and keep `.pad` filling the seat. This edit is to floor rules this change added, and is in scope.
- `site/floor.html`: its nav links only to pages that exist (`npm test` must find no broken link); the nav may list master's pages. Doctype, `<html lang="en">`, `<meta charset="utf-8">`, `<title>`, stylesheet link and `<main>` match the other pages and are in scope. Otherwise unchanged.
- `site/index.html`: relative to master, the only change is the one added Floor line.
- Not in scope: JavaScript, drag to orbit, live data, opening threads (all #17); editing other pages; changing `site/loop.html` and the pages master added.

## Constraints

- May touch only `site/floor.html`, `site/index.html` and `site/style.css`. Files under `factory/` do not count.
- Must not change `check.mjs`, `package.json`, `README.md`, any other file under `site/`, or any line already on master in `site/index.html` or `site/style.css`.
- Must not add dependencies, a build step, images, `<script>`, `<canvas>`, or any file outside `site/`.
- Budget, measured against master (`git diff --numstat origin/master...HEAD`, excluding `factory/`): at most 3 files changed, at most 250 added lines and 0 removed lines in total.
