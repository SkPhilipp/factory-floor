# Plan for #11, attempt 2

## Goal

Add `site/floor.html`, "The floor", and link it from the nav on `site/index.html` as "Floor", as in attempt 1's plan (`factory/plans/11-1.md`): the issue's intro, the Fact / Source / Readable as table with nine rows, a static CSS 3D scene of five phase columns with pads, lights, cards, strike dots and timeout bars, a throughput tally, and the closing paragraph on the ideas that did not ship first. No JavaScript, no canvas, no WebGL. Live state, orbit and click-through stay in #17, already filed with label `factory`.

Attempt 1 built this and passed its gate, but failed Review because the branch does not merge into master: master gained `site/loop.html` (#2), a Loop nav item in `site/index.html` and a `pre` rule at the end of `site/style.css`, which conflict with this branch's appended nav item and floor rules. This attempt keeps the attempt 1 page and makes the branch merge cleanly.

## Scope

- First step: run `git fetch origin && git merge origin/master` on this branch (a merge commit, no rebase, no force-push) and resolve the two conflicts, in `site/index.html` and `site/style.css`, by keeping both sides. In `site/index.html` the nav ends up with Home, The loop and Floor, in that order. In `site/style.css` master's `pre` rule stays and the floor rules follow it.
- `site/floor.html`: already exists on this branch and is reused. Its nav must match master's, listing Home, The loop and Floor, so that `npm test` finds no broken link. Doctype, `<html lang="en">`, `<meta charset="utf-8">`, `<title>`, stylesheet link and `<main>` match the other pages and are in scope.
- `site/index.html`: the only change relative to master is one added `<li><a href="floor.html">Floor</a></li>` after The loop.
- `site/style.css`: relative to master, only floor rules are added. Existing master rules stay as they are.
- `site/loop.html` is taken from master unchanged. Adding a Floor link to its nav is optional and, if done, is one added line and in scope.
- Page content, sample state and inertness (no `animation`, `@keyframes` or timers; `transition` only) are as in `factory/plans/11-1.md`: five columns Backlog, Intake, Build, Review, Release; 5 pads in the sample (Intake 1, Build 2, Review 1, Release 1, the Release light green); cards for waiting, held, strikes, hot timeout bar, failed and merged; card `href`s are `#`.
- Not in scope: JavaScript, drag to orbit, live data, opening threads (all #17).

## Constraints

- May touch only `site/floor.html`, `site/index.html`, `site/style.css` and, optionally, `site/loop.html`. Files under `factory/` do not count.
- Must not change `check.mjs`, `package.json`, `README.md`, or any line already on master in `site/index.html`, `site/style.css` or `site/loop.html`, other than the added nav lines.
- Must not add dependencies, a build step, images, `<script>`, `<canvas>`, or any file outside `site/`.
- Budget, measured against master (`git diff --numstat origin/master...HEAD`, excluding `factory/`): at most 4 files changed, at most 300 added lines and at most 1 removed line in total.
