# Plan for #12, attempt 2

## Goal

Add a Principles page to the Dark Factory site: `site/principles.html`, titled "Principles", using the shared stylesheet, holding the nine principles from the issue as a list with a bold lead-in per item, closed by a "Why three" section. Link it from the nav on `site/index.html` as "Principles". One small pull request; no split.

Attempt 1 built exactly this and every acceptance criterion held. It failed only because one proof command, a `grep -c` for inline styles, exits 1 when it finds no match, and the gate treats a non-zero exit as failure. The page and nav link are already on this branch (draft PR #19). Build continues from them: it verifies them against this plan and changes `site/` only if a criterion below does not hold. The fix in this attempt is to the proofs, which now exit 0 when nothing matches.

## Scope

- `site/principles.html`: `<!DOCTYPE html>`, `<html lang="en">`, `<meta charset="utf-8">`, `<title>Principles</title>`, `<link rel="stylesheet" href="style.css">`, a `<main>` wrapper, an `<h1>Principles</h1>`, and the same `<nav>` as the index page (Home and Principles). These are what a valid, conventional page in this site needs and are planned, not unrequested.
- The list is one `<ul>` with nine `<li>` items, each starting with a `<strong>` lead-in (the first sentence of the issue bullet) followed by the rest of that bullet's text verbatim, in the issue's order.
- After the list, an `<h2>Why three</h2>` followed by one `<p>` with the closing paragraph of the issue, verbatim.
- `site/index.html`: one added `<li><a href="principles.html">Principles</a></li>` in the existing nav list. The existing "Home" link, `<h1>` and paragraph are kept.

## Constraints

- May touch only `site/principles.html` and `site/index.html`. `site/style.css`, `check.mjs`, `package.json` and `README.md` must not change. Files under `factory/` do not count.
- Must not add dependencies, a build step, JavaScript, inline `<style>` or `style=` attributes, or other pages.
- Must not reword the issue's text; only HTML escaping and wrapping the lead-in in `<strong>` are allowed. The backticked `main` may be `<code>`.
- Budget: at most 2 files changed and under 50 added lines in total, outside `factory/`.

- [ ] No file other than the two named in Constraints changes outside `factory/`.
