# Plan for #17, attempt 6

## Goal

Make `site/floor.html` live from one same-origin file, `site/state.json` (the site stays static; producing that file from GitHub and bb threads is #28, `Depends on #17`, still open). The branch already carries the attempt 5 code, which met every attempt 5 criterion. Review (`factory/reviews/17-5.md`) found three defects, all in the DOM path of `main` in `site/floor.js`, and all are the work of this attempt:

1. Spare seats are not hidden: `seat.hidden = true` is overridden by `.seat { display: flex }`. Hidden seats and columns must really disappear in a browser.
2. Columns are only ever added. A phase that disappears from a later fetch keeps its column, and a changed phase order is not reflected. Columns must follow the model: columns of phases no longer in the state are hidden (kept for reuse), the rest are in model order.
3. Queue order is not reconciled: a card is appended only when its slot changes, so after an earlier queued item leaves, or the queue order changes, the DOM order differs from the model order. Cards inside a queue must be in model order after every fetch.

The earlier rule stays: a card is reparented only when its slot (`slotOf`) differs from its slot on the previous fetch; per-fetch updates never reparent. Reordering within the same queue is allowed (it is not a slot change) and is done only when the DOM order differs from the model order.

To make the DOM path testable without a DOM, derive it from a pure exported function `layout(model)` returning, in model order, one entry per column: `{ id, seats: [{ index, card }], queue: [numbers in order] }` (`card` is the item number or `null`). `main` applies `layout`: it shows exactly the columns and seats in the layout, hides every other column and seat, and places queue cards in the layout's order. Tests assert `layout` for disappearing phases, reordered phases and queue changes.

Everything else stays as on the branch: `state.json` shape (`phases` of `{id,title,seats,timeout_s,agent}`, `items` of `{number,title,phase,status,strikes,thread_url,issue_url,started_at,defect}`), `barState`, `tally`, `orbit`, `cardHref`, `buildModel`, `slotOf`, `slotsOf`, fetch error display, touch orbit.

Nothing else changes behaviour.

- Files kept valid and conventional on the branch (not unrequested): `site/floor.html` (doctype, charset, title, stylesheet link, module script), `package.json` (`scripts.test` exactly `node check.mjs && node --test test/*.test.mjs`), `site/state.json`, and the exported helper `slotsOf` already on the branch.
