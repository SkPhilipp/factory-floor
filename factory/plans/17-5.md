# Plan for #17, attempt 5

## Goal

Make `site/floor.html` live from one same-origin file, `site/state.json` (the site stays static; producing that file from GitHub and bb threads is #28, `Depends on #17`). The branch already carries the attempt 4 code, which passed every criterion except one. Review (`factory/reviews/17-4.md`) found two defects, both in the DOM path of `main` in `site/floor.js`, and both are the work of this attempt:

1. Columns and seat elements are built once from the first fetch. If a later fetch has more seats or more phases, a running item is placed nowhere (`if (!seats[n]) return;`) or the render throws (`columns[c]` undefined). The DOM must be reconciled to the model on every fetch: missing columns and seats are created, so every card of the model is rendered.
2. `el.parentNode !== parent` reparents a card whenever its slot shifts. The rule is restated precisely: a card is reparented only when its slot differs from the slot it had on the previous fetch, where a slot is the phase plus either a seat index or the queue. Per-fetch updates (title, dots, bar, defect, href) never reparent it. The slot is computed by a pure, exported function so a test can assert it. Extra seats beyond the model's count are kept in the DOM but hidden as spare.

Everything else from attempts 2 to 4 stays as it is on the branch: `state.json` shape (`phases` of `{id,title,seats,timeout_s,agent}`, `items` of `{number,title,phase,status,strikes,thread_url,issue_url,started_at,defect}`), `barState`, `tally`, `orbit`, `cardHref`, `buildModel`, fetch error display, touch orbit.

## Scope

- `site/floor.js`: add an exported pure `slotOf(phaseId, entry, index)` (or equivalent name, exported) returning a string slot id such as `build/seat/0` or `build/queue`; make `render` create missing columns and seats on every fetch (replace the build-once `if (!columns.length) build(model)` and drop the `if (!seats[n]) return;` skip); reparent a card only when `slotOf` differs from the stored slot. Nothing else in the file changes behaviour.
- `test/floor.test.mjs`: add tests for `slotOf` (same item with unchanged slot gives the same id across two builds of the same state; a running item moving from seat 1 to seat 0 gives a different id; a queued item gives the queue id) and for `buildModel` with a phase whose `seats` grows from 1 to 3 across two states, asserting every running item still appears exactly once.
- Files kept valid and conventional on the branch (not unrequested): `site/floor.html` (doctype, charset, title, stylesheet link, module script), `package.json` (`scripts.test` exactly `node check.mjs && node --test test/*.test.mjs`, nothing else), `site/state.json`, `site/style.css` as already changed on the branch. They need no new edits.
- Behaviour rules unchanged: nothing animates on a timer (only the re-fetch `setInterval`, at most one, no shorter than 15 s), no `requestAnimationFrame`, no `@keyframes`; a defect stays until a fetch sets it to `null`; `touch-action: none` on `.scene`.
