# Plan for #17, attempt 2

## Goal

Make `site/floor.html` live now that #11 has landed on `master`. Decision on where state is read from: the site stays static, so the page fetches one same-origin file, `site/state.json`, and renders every card from it. The file's shape is the contract between the loop and the floor (below). This pull request ships the contract, a committed sample `state.json`, the renderer, orbit, click-through, the timeout bar and the tally. Producing `state.json` from GitHub issues, labels and bb threads is split into its own issue (see Scope) because it needs credentials and a publishing path that a static page does not have.

`state.json` shape:

- `phases`: array of `{ "id", "title", "seats", "timeout_s", "agent" }`, in column order; ids are `backlog`, `intake`, `build`, `review`, `release`. `agent: false` marks the phase with no agent.
- `items`: array of `{ "number", "title", "phase", "status", "strikes", "thread_url", "issue_url", "started_at", "defect" }`. `status` is one of `waiting`, `running`, `failed`, `merged`. `strikes` is 0 to 5. `thread_url`, `started_at` (ISO 8601) and `defect` (string) may be `null`.

## Scope

- `site/floor.js` (new): an ES module. Pure, exported, DOM-free functions: `barState(item, phase, nowMs)` returning `{ pct, hot }`, `tally(items)`, `orbit(angles, dx, dy)`, `cardHref(item)`. A browser-only `main` guarded by `typeof document !== "undefined"` that fetches `state.json`, renders columns, seats and cards, wires drag-to-orbit, and re-fetches the state at an interval no shorter than 15 seconds.
- `site/floor.html`: remove the hard-coded sample `.card` elements and the sample tally numbers, leaving empty containers the script fills; add `<script type="module" src="floor.js"></script>`. Keep the heading, the intro paragraph, the table, the nav and the "Ideas that did not ship first" paragraph. Keep the file valid for `check.mjs` (doctype, charset, title, stylesheet link, no broken links).
- `site/state.json` (new): a sample state with at least one item per status and per phase, one item with strikes, one with a `defect`, one running item with `started_at` and `thread_url`.
- `site/style.css`: only what the live page needs: a cursor style for the draggable `.scene`, a `.defect` rule for the card's defect text, and a rule for a spare seat (empty pad, light off). Existing rules are kept.
- `test/floor.test.mjs` (new) and `package.json`: `scripts.test` becomes `node check.mjs && node --test test/`. This is the minimum for the new tests to run under `npm test`; `scripts.test` otherwise keeps its form.
- Behaviour rules the code and tests must follow:
  - Nothing animates on a timer: the only timer is the state re-fetch; a card moves only when its item's `phase` or `status` differs from the previous fetch, by changing its classes so the existing CSS transitions play. No `requestAnimationFrame` and no `@keyframes`.
  - `status: running` puts the card in a seat with the light on; `waiting` puts it in the phase queue; `failed` gives `.failed`; `merged` gives `.merged`.
  - Dots: `strikes` filled dots out of five.
  - Timeout bar: `pct = clamp((now - started_at) / (timeout_s * 1000), 0, 1) * 100`, `hot` when `pct >= 80`; no `started_at` gives 0.
  - A `defect` string stays rendered on the card while it is non-null; the renderer never clears it on its own, only a state fetch where `defect` is `null` removes it.
  - Click-through: a card links to `thread_url` when set, otherwise to `issue_url`.
  - Orbit: dragging the pointer over `.scene` changes its `rotateX` (clamped to 20 to 80 degrees) and `rotateY` (clamped to -45 to 45); the default stays `rotateX(50deg)`.
  - Tally: merged = items with `status` `merged`; failed = items with `status` `failed`; retried = items with `strikes` above 0 and a status other than `failed`.
- Split off, not in this pull request: a producer that writes `site/state.json` from GitHub (issues, `factory:*` and `strike:*` labels, running bb threads, phase timeouts, seats) in the shape above. Filed as a new issue that says `Depends on #17`.

## Constraints

- May touch only `site/floor.html`, `site/floor.js`, `site/state.json`, `site/style.css`, `package.json` and `test/floor.test.mjs`. Files under `factory/` do not count.
- Must not change `check.mjs`, any other page, the `.html` structure outside the floor markup described in Scope, or any existing CSS rule's values.
- Must not add dependencies, a lockfile, a build step, a framework, or a server.
- Budget: at most 6 files changed and 400 added lines in total, outside `factory/`.

- [ ] `barState` gives `pct` 50 and `hot` false at half the timeout, `hot` true from 80, `pct` capped at 100, and `pct` 0 with no `started_at`; a test asserts each.
