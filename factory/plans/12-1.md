# Plan for #12, attempt 1

## Goal

Add a Principles page to the Dark Factory site: `site/principles.html`, titled "Principles", using the shared stylesheet, holding the nine principles from the issue as a list with a bold lead-in per item, closed by a "Why three" section. Link it from the nav on `site/index.html` as "Principles". The issue fits one small pull request; no split.

## Scope

- `site/principles.html` (new): `<!DOCTYPE html>`, `<html lang="en">`, `<meta charset="utf-8">`, `<title>Principles</title>`, `<link rel="stylesheet" href="style.css">`, a `<main>` wrapper, an `<h1>Principles</h1>`, and the same `<nav>` as the index page (Home and Principles) so the page can be left. These are what a valid, conventional page in this site needs and are planned, not unrequested.
- The list is one `<ul>` with nine `<li>` items, each starting with a `<strong>` lead-in (the sentence-initial phrase of the issue bullet, e.g. "Issues as queue, labels as state.") followed by the rest of that bullet's text verbatim, in the issue's order.
- After the list, an `<h2>Why three</h2>` followed by one `<p>` with the closing paragraph of the issue, verbatim.
- `site/index.html`: add one `<li><a href="principles.html">Principles</a></li>` to the existing nav list. Nothing else changes; the existing "Home" link, `<h1>` and paragraph are kept.
- `site/style.css`: not changed unless the page is unreadable without it; the existing rules already style `ul`, `li`, `h2` and `a`.

## Constraints

- May touch only `site/principles.html` and `site/index.html`. `site/style.css`, `check.mjs`, `package.json` and `README.md` must not change. Files under `factory/` do not count.
- Must not add dependencies, a build step, JavaScript, inline `<style>` or `style=` attributes, or other pages.
- Must not reword the issue's text; only HTML escaping (`&amp;`, `&lt;`) and wrapping the lead-in in `<strong>` are allowed. Backticked words in the issue (`main`) may become `<code>`.
- Budget: at most 2 files changed and under 50 added lines in total, outside `factory/`.

## Acceptance criteria

- [ ] `site/principles.html` exists, has `<title>Principles</title>` and the line `<link rel="stylesheet" href="style.css">`.
- [ ] `site/principles.html` contains exactly nine `<li>` items that begin with `<strong>`, in the order of the issue, each lead-in being the first sentence of its bullet.
- [ ] `site/principles.html` contains an `<h2>Why three</h2>` that comes after the list and is followed by a paragraph that starts "One agent doing all three phases".
- [ ] `site/index.html` nav contains `<a href="principles.html">Principles</a>` and still contains `<a href="index.html">Home</a>`.
- [ ] `site/index.html` differs from the base only by that one added nav item.
- [ ] No inline styles, scripts or external resources are added.
- [ ] No file other than the two named in Constraints changes outside `factory/`.
