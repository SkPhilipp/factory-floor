# Plan for #17, attempt 3

## Goal

Make `site/floor.html` live now that #11 has landed on `master`. Where state is read from: the site stays static, so the page fetches one same-origin file, `site/state.json`, and renders every card from it. The file's shape is the contract between the loop and the floor (below). This pull request ships the contract, a committed sample `state.json`, the renderer, orbit, click-through, the timeout bar and the tally. Producing `state.json` from GitHub issues, labels and bb threads is split into #28 (depends on #17), because it needs credentials and a publishing path a static page does not have.

Attempt 2 built this and Review (`factory/reviews/17-2.md`) found six defects. They are criteria here: a running item beyond the seat count must not vanish; the timeout bar must not produce `NaN` or `Infinity`; fetch failure must be visible; a card must move in the DOM only when its `phase` or `status` changed; a retitled issue must update; orbit must work on touch. It also found `scripts.test` lacking the `test/` argument. The attempt 2 code may exist on a branch for reference; the result must satisfy the criteria below measured against `origin/master`.

`state.json` shape:

- `phases`: array of `{ "id", "title", "seats", "timeout_s", "agent" }`, in column order; ids are `backlog`, `intake`, `build`, `review`, `release`. `agent: false` marks a phase with no agent.
- `items`: array of `{ "number", "title", "phase", "status", "strikes", "thread_url", "issue_url", "started_at", "defect" }`. `status` is one of `waiting`, `running`, `failed`, `merged`. `strikes` is 0 to 5. `thread_url`, `started_at` (ISO 8601) and `defect` (string) may be `null`.

## Scope

- `site/floor.js` (new): an ES module. Pure, exported, DOM-free functions: `barState(item, phase, nowMs)` returning `{ pct, hot }`, `tally(items)`, `orbit(angles, dx, dy)`, `cardHref(item)`, and `buildModel(state, nowMs)` returning per phase `{ phase, seats, queue }`. A browser-only `main` guarded by `typeof document !== "undefined"` fetches `state.json`, renders columns, seats and cards, wires drag-to-orbit, and re-fetches at an interval no shorter than 15 seconds.
- `site/floor.html`: remove the hard-coded sample `.card` elements and the sample tally numbers, leaving empty containers the script fills; add `<script type="module" src="floor.js"></script>`. Keep the heading, the intro paragraph, the table, the nav and the "Ideas that did not ship first" paragraph. Keep the file valid for `check.mjs` (doctype, charset, title, stylesheet link, no broken links).
- `site/state.json` (new): a sample state with at least one item per status and per phase, one item with strikes, one with a `defect`, one running item with `started_at` and `thread_url`.
- `site/style.css`: only what the live page needs: a cursor style and `touch-action: none` for the draggable `.scene`, a `.defect` rule, a rule for a spare seat (empty pad, light off), and a rule for a load-error message. Existing rules are kept.
- `test/floor.test.mjs` (new) and `package.json`: `scripts.test` becomes exactly `node check.mjs && node --test test/`. This is the minimum for the new tests to run under `npm test`; `package.json` is otherwise unchanged. The file is `package.json` with the existing `scripts.test` form kept, nothing else added (no `type` field, no dependencies).
- Behaviour rules the code and tests must follow:
  - Nothing animates on a timer: the only timer is the state re-fetch; a card moves only when its item's `phase` or `status` differs from the previous fetch, by changing its classes so existing CSS transitions play. Per-fetch updates (title, dots, bar, defect, href) change the card in place and never remove or reparent it. No `requestAnimationFrame` and no `@keyframes`.
  - `status: running` puts the card in a free seat with the light on; `waiting` puts it in the phase queue; `failed` gives `.failed`; `merged` gives `.merged`. A running item with no free seat (more running items than `seats`, or `seats: 0`) goes to the queue instead of disappearing: every item in `state.items` whose `phase` matches a phase appears exactly once in the model.
  - Dots: `strikes` filled dots out of five.
  - Timeout bar: `pct = clamp((now - started_at) / (timeout_s * 1000), 0, 1) * 100`, `hot` when `pct >= 80`. `pct` is 0 and `hot` false when `started_at` is null, unparseable, or `timeout_s` is not above 0. `pct` is always a finite number.
  - A `defect` string stays rendered on the card while it is non-null; only a fetch where `defect` is `null` removes it.
  - Card title text is refreshed on every fetch.
  - Fetch: a non-OK response or invalid JSON shows a message in an element with class `load-error` and keeps the last good render; a later good fetch clears it.
  - Click-through: a card links to `thread_url` when set, otherwise to `issue_url`.
  - Orbit: dragging over `.scene` changes `rotateX` (clamped 20 to 80 degrees) and `rotateY` (clamped -45 to 45); the default stays `rotateX(50deg)`.
  - Tally: merged = items with `status` `merged`; failed = `status` `failed`; retried = `strikes` above 0 and status other than `failed`.
- Split off, not in this pull request: the producer that writes `site/state.json` from GitHub, filed as #28 with `Depends on #17`.

## Constraints

## Acceptance criteria

- [ ] `site/floor.js`, `site/state.json` and `test/floor.test.mjs` exist, and `site/floor.html` loads `floor.js` as a module.
- [ ] `site/floor.html` has no hard-coded `.card` elements and no sample tally numbers; it still has the table, nav and the Home, Release, The loop and Floor links.
- [ ] `site/state.json` is valid JSON with `phases` (the five ids in order) and `items`, every item with a valid `phase`, a valid `status` and `strikes` 0 to 5; it covers every status, a defect, a strike and a running item with `started_at` and `thread_url`.
- [ ] `barState` gives `pct` 50 and `hot` false at half the timeout, `hot` true from 80, `pct` capped at 100, and `pct` 0 with no `started_at`; a test asserts each.
- [ ] `barState` returns `pct` 0 and `hot` false, with a finite `pct`, for `timeout_s: 0` with a `started_at`, and for an unparseable `started_at`; a test asserts both.
- [ ] `buildModel` places a third running item of a phase with 2 seats in the queue, and every running item of a phase with `seats: 0` in the queue; a test asserts that all items appear exactly once.
- [ ] `tally` counts as defined in Scope; a test asserts it on a hand-made list, and a second list with one extra merged item changes only `merged`.
- [ ] `orbit` clamps both angles; a test asserts both limits.
- [ ] `cardHref` returns `thread_url` when set and `issue_url` otherwise; a test asserts both.
- [ ] A defect in the model is kept when the same state is built again; a test asserts it.
- [ ] `site/floor.js` has no `requestAnimationFrame`, `site/style.css` has no `@keyframes`, and `setInterval` appears at most once.
- [ ] `site/floor.js` checks `r.ok` on the fetch and has no empty `catch(() => {})`; it uses a `load-error` element.
- [ ] `site/floor.js` does not remove and re-append every card on each fetch: it never calls `.remove()` on `.seat` or `.queue` nodes in the render loop, and only reparents a card when its `phase/status` key changed. (Checked in review by reading the diff.)
- [ ] The card title is assigned from `item.title` outside `makeCard` (refreshed per fetch).
- [ ] `site/style.css` has `touch-action: none` on `.scene`.
- [ ] `package.json` `scripts.test` equals `node check.mjs && node --test test/`.
- [ ] No file outside the six in Constraints is changed relative to `origin/master`.
