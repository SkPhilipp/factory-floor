# Plan for #1, attempt 2

## Goal
Scaffold the Dark Factory static site: a home page, a dark stylesheet, and a Node check command, so later issues can each add one page.

## Scope
- `site/index.html`: title "The Dark Factory"; one paragraph "A dark factory runs with the lights off. Work goes in, reviewed pull requests come out, and nobody watches the loop. A human reads results, not progress."; below it a `<nav>` with a `<ul>` holding a single link to `index.html` labelled "Home"; links `<link rel="stylesheet" href="style.css">`.
- `site/style.css`: background `#151517`, text `#f2f3f5`, muted text `#b8bcc4`, link accent `#7fb58a`, system sans-serif body, serif headings, content column max-width 760px, tables with a 1px `#2e2e31` border.
- `package.json`: `"scripts": { "test": "node check.mjs" }`, no dependencies.
- `check.mjs`: walks `site/`; for each `.html` file reports a problem line if it lacks `<title>`, lacks `<link rel="stylesheet" href="style.css">`, or has a relative `href` to a file not present in `site/`; exits non-zero on any problem; prints `ok: N pages` on success.
- `README.md`: two sentences on what the site is, and `npm test` as the check.

The issue fits in one pull request; no split needed.

## Constraints
- May touch only: `site/index.html`, `site/style.css`, `package.json`, `check.mjs`, `README.md`.
- Must not change: git history of the base branch, any other file. No dependencies, no framework, no build step, no JavaScript in the site.
- Budget: at most 5 files changed, at most 200 added lines in total.

## Acceptance criteria
- [ ] `site/index.html`, `site/style.css`, `package.json`, `check.mjs` exist and `README.md` is updated.
- [ ] `package.json` has the `test` script `node check.mjs` and no `dependencies` or `devDependencies` key.
- [ ] `site/style.css` contains `#151517`, `#f2f3f5`, `#b8bcc4`, `#7fb58a`, `#2e2e31`, and `760px`.
- [ ] `site/index.html` contains the exact paragraph text from the issue and a `<nav>` whose list has one link `index.html` labelled "Home".
- [ ] `check.mjs` reports a problem and exits non-zero for a page missing `<title>`, missing the stylesheet link, or with a broken relative `href`.
- [ ] `README.md` is two sentences and mentions `npm test`.
- [ ] No files outside the Scope list changed (other than under `factory/`).

## Proofs
- `npm test` — exits 0 and prints `ok: 1 pages`.
- `test -f site/index.html && test -f site/style.css && test -f check.mjs && test -f package.json` — exits 0.
- `grep -c "The Dark Factory" site/index.html` — prints a number of 1 or more.
- `grep -q "<nav>" site/index.html && grep -q 'href="index.html"' site/index.html` — exits 0.
- `grep -q "760px" site/style.css && grep -q "#151517" site/style.css` — exits 0.
- `sh -c 'd=$(mktemp -d) && cp -r site "$d/site" && echo "<p>x</p>" > "$d/site/bad.html" && cp check.mjs "$d/" && cd "$d" && ! node check.mjs'` — exits 0, proving the check fails on a page lacking title and stylesheet.
