## Defects

1. Spare seats are not actually hidden. `site/floor.js:169-171` sets `seat.hidden = true` on seats beyond the model's count, but `.seat { display: flex }` (`site/style.css:69-72`) overrides the UA `[hidden]` rule. After seats shrink (for example 3 to 1) the extra seat boxes still render with a grey light, so the plan's "kept in the DOM but hidden as spare" is not met in a browser. The tests do not cover this because they run without a DOM.
2. Columns are only ever added. `ensureColumn` (`site/floor.js:124-140`) never hides or removes the column of a phase that disappears from a later fetch, and a changed phase order is not reflected. The stale column keeps its heading and seats, and its seats are not hidden because only phases in the model are iterated (`site/floor.js:153`). This contradicts the plan's "DOM reconciled to the model on every fetch".
3. Queue order is not reconciled. A card is appended only when its slot changes (`site/floor.js:163`). If an earlier queued item leaves, or the order of queued items changes within the same slot, the remaining cards keep their old DOM order and no longer match the model order.
